# Bundle

This directory documents the GitHub-ready payload for `gemini-unchained-blueprint`.

Included in the publishable bundle:

- install scripts
- daemon runtime source
- prompt templates
- task schema example
- quick install docs
- tests

Not included:

- copied auth files
- live daemon runtime state
- local logs
- task history from a real machine

Treat the bundle as a portable starter kit, not as a sync of any private node’s live runtime.
